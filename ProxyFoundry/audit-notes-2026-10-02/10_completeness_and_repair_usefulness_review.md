# Audit usefulness and limits

This package maps the relevant execution/storage surfaces and identifies concrete
entry points, measured failures, repairs and regression checks. It is sufficient
to continue the overnight responsiveness work without repeating the baseline.

It is a scoped performance audit. Actual large-deck timings, filesystem overlap,
long-session memory and renderer concurrency are pending. Synthetic job timings
must not be presented as measured deck speedups. Remaining findings will be
rechecked against each milestone's source and real browser behavior.
