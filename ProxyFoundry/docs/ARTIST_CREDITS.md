# Artist credits in Bulk Proxy Forge

Scryfall artwork always uses the artist credited on the selected printing, face-specific when available. Its printed artist line is:

`Artist Name (Scryfall) • Art © respective rights holders`

Custom artwork uses the per-face artist when provided, otherwise the deck custom-art artist. A custom image may explicitly retain the selected printing artist when appropriate.

There is no modification-credit or “Art modified by” field.

Every generated card uses the footer:

`BulkProxyForge • Unofficial Proxy`
