Scryfall Full Card Image Downloader

1. Double-click run.bat.
2. Paste a public Scryfall deck link, for example:
   https://scryfall.com/@andro951/decks/ce5b8abe-ec82-4813-b259-9b4faaa6bd66
3. Click "Download Full Card Images".
4. Use "Open Output Folder" to open the generated folder and ZIP.

The app uses the exact printings selected in the Scryfall deck and downloads full-card PNG images, not cropped artwork.
Double-faced cards download both full card faces.
Duplicate copies of the same exact card printing are downloaded once.

Requires Python 3 and internet access. No third-party Python packages are required.
